# Google Play store listing: Critter Ranch Tycoon

Copy these into **Play Console → Grow users → Store presence → Main store listing**.
The character limits are Play's. The counts are checked by `python3` (see the bottom of this file).

Search on Play reads the **app name** most, then the **short description**, then the full description
(the first lines count most). Players type words like *idle*, *tycoon*, *pet*, *monster*, *farm* and
*catch*, so those appear in all three, written as normal sentences. Repeating them as a list
(keyword stuffing), "best"/"#1", prices or emojis in the name are against Play policy.
